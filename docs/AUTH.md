# Google 로그인 유지

IdeaDock은 GitHub Pages 정적 사이트이며 Google Identity Services(GIS) **토큰 모델**로 Drive에 접근합니다. 토큰 모델은 팝업으로 최대 1시간짜리 액세스 토큰만 발급하고, 리프레시 토큰을 주지 않습니다. 따라서 정적 호스팅만으로는 "사용자 조작 없는 장기 로그인"을 만들 수 없습니다. 이 문서는 그 한계 안에서 선택한 방식과 보안 검토, 그리고 서버를 두는 대안을 정리합니다.

## 동작

| 상황                        | 결과                                                                                                                                                                          |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 처음 로그인                 | 계정 선택 창(`prompt: select_account`)                                                                                                                                        |
| 같은 탭에서 F5 (1시간 이내) | 클릭 없이 연결 유지. 토큰을 `sessionStorage`에서 복원                                                                                                                         |
| PWA·탭을 닫았다가 다시 실행 | 마지막 작업 공간이 기기 캐시(아이디어·폴더·이미지)로 즉시 열림. 상단/하단에 **Drive 다시 연결** 한 번 탭 → `login_hint` + `prompt: ""`로 계정 선택·동의 화면 없이 토큰 재발급 |
| 토큰 만료·취소(1시간, 401)  | 오류 대신 재연결 배너. 편집은 계속 가능하고 기기(IndexedDB)에 보관, 재연결 즉시 동기화                                                                                        |
| 다른 계정으로 전환          | 설정 → **다른 Google 계정으로 전환**(계정 선택 창). 미저장 초안이 있으면 팝업 전에 거부                                                                                       |
| 로그아웃                    | 토큰과 기억된 계정을 모두 삭제. 새로고침 후 이전 계정 데이터가 화면에 나오지 않음                                                                                             |

재연결이 팝업을 쓰는 이유: GIS는 `requestAccessToken`을 버튼 클릭 같은 사용자 동작에서 호출하도록 요구하며, 그 외에는 팝업 차단으로 실패합니다. 자동(무음) 갱신은 구현하지 않았습니다.

## 저장 위치와 보안 검토

| 키                       | 저장소           | 내용                                   | 수명                                                                       |
| ------------------------ | ---------------- | -------------------------------------- | -------------------------------------------------------------------------- |
| `ideadock:drive-account` | `localStorage`   | Google `sub`, 이메일, 이름 (비밀 아님) | 로그아웃 시 삭제                                                           |
| `ideadock:drive-session` | `sessionStorage` | 액세스 토큰, 만료 시각, 위 계정 정보   | 탭 단위. `min(expires_in, 1시간) − 30초`, 로그아웃·401·계정 불일치 시 삭제 |

- **토큰은 영구 저장하지 않습니다.** `sessionStorage`는 탭(또는 PWA 창)이 닫히면 사라지고, 만료된 토큰은 복원하지 않습니다. Google이 1시간보다 긴 수명을 돌려줘도 1시간으로 자릅니다.
- **권한 범위가 좁습니다.** `drive.file`(IdeaDock이 만든 파일만)과 `openid email profile`뿐입니다. 리프레시 토큰·클라이언트 시크릿은 브라우저에 없습니다.
- **XSS 노출은 메모리 보관과 같은 수준입니다.** 같은 페이지에서 스크립트가 실행되면 메모리의 토큰도 가로챌 수 있으므로 `sessionStorage`가 공격 면을 크게 넓히지 않습니다. 반면 토큰이 탭 밖으로 퍼지지 않도록 `localStorage`는 쓰지 않습니다.
- **계정 격리:** 저장된 토큰은 기억된 계정과 일치할 때만 복원됩니다. 캐시는 기존처럼 `google:<sub>` 접두어로 계정마다 분리됩니다. 로그아웃하면 기억된 계정이 지워져 재실행 시 이전 계정 캐시를 열지 않습니다(IndexedDB의 초안·이미지 자체는 데이터 보존을 위해 삭제하지 않습니다).
- **같은 원본의 다른 앱:** `oyueo-mm.github.io`의 TransitLog 등은 같은 원본이라 IdeaDock의 `localStorage`·IndexedDB를 읽을 수 있습니다. 이는 이번 변경 이전부터의 신뢰 경계입니다. `sessionStorage`의 토큰은 같은 탭에서 그 앱으로 이동했을 때만 읽을 수 있습니다. 완전히 분리하려면 IdeaDock 전용 도메인이 필요합니다.
- **기기 접근:** 로그아웃하지 않은 기기를 다른 사람이 열면 캐시된 아이디어를 볼 수 있습니다(Drive 쓰기는 Google 재인증 필요). 공용 기기에서는 로그아웃하세요.

## 실기기 확인 필요 항목

자동 테스트는 Playwright Chromium(데스크톱·모바일 에뮬레이션)과 모의 GIS·Drive로 수행합니다. 다음은 자동화로 증명할 수 없습니다.

- 실제 Google 계정에서 `prompt: ""` + `login_hint` 팝업이 화면 없이 바로 닫히는지(이미 동의한 사용자, 브라우저에 Google 로그인 유지 중일 때)
- Android 삼성 인터넷 설치형 PWA에서 GIS 팝업이 열리고 토큰을 앱 창으로 돌려주는지
- PWA를 종료할 때 OS가 `sessionStorage`를 지우는 시점(백그라운드 전환만으로는 유지될 수 있음)

## 장기 로그인이 꼭 필요할 때: 인증 서버 비교

재실행할 때마다 한 번 탭하는 것도 없애려면 **리프레시 토큰을 보관하는 서버**가 필요합니다(GIS 코드 모델 + 클라이언트 시크릿).

| 항목                  | 현재(정적, 토큰 모델)      | Cloudflare Workers + 자체 도메인                                                                                                                                          | Supabase Edge Functions                              |
| --------------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| 재실행 시 사용자 조작 | 재연결 1탭(계정 선택 없음) | 없음(쿠키로 새 액세스 토큰 발급)                                                                                                                                          | 없음                                                 |
| 비용                  | 0원                        | Workers 무료 등급(일 10만 요청) + 도메인 연 약 1.5~2만 원                                                                                                                 | 무료 등급(프로젝트 일시정지 정책 있음) + 도메인 필요 |
| 필수 변경             | 없음                       | 앱과 API를 **같은 사이트**(예: `ideadock.example.com`, `api.ideadock.example.com`)로 이전. github.io와 다른 사이트면 서드파티 쿠키로 취급되어 삼성 인터넷·Safari에서 막힘 | 동일(쿠키 도메인 문제)                               |
| 보안 부담             | 낮음                       | 클라이언트 시크릿·리프레시 토큰 암호화 보관, httpOnly·SameSite 쿠키, CSRF 방어, 토큰 폐기 처리                                                                            | 동일 + 서비스 롤 키 관리                             |
| Google 설정           | 현재 그대로                | OAuth 앱을 **프로덕션** 상태로 전환해야 함(테스트 상태 리프레시 토큰은 7일 만료). 승인 원본·리디렉션 URI 추가                                                             | 동일                                                 |
| 데이터 영향           | 없음                       | 원본이 바뀌므로 기기의 IndexedDB 캐시·초안을 새 주소로 옮겨야 함(Drive 데이터는 그대로)                                                                                   | 동일                                                 |

권장: 현재 방식으로 운영하면서 실기기에서 재연결 1탭이 불편하다고 확인되면, 전용 도메인 확보와 함께 Cloudflare Workers 방식으로 전환합니다. 전용 도메인은 Android Chrome의 같은 원본 PWA 설치 문제([PAGES.md](PAGES.md#pwa-설치))도 함께 해결합니다.
